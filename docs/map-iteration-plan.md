## 迭代顺序与验收门槛

### 第 0 轮：基线与计划（已完成）

交付本计划、覆盖盘点、参考能力证据及本次浏览器结果。当前线上“云端浏览器未执行”的旧报告仍未更新；第一轮发布时应按真实执行结果重建验证报告。

### 第 1 轮：基础探索图层（P0，已实现）

首批只接入 **魔力之所、告示板、储藏箱，共 72 条冻结候选记录**；先验证、去重，再发布实际接入数。提供分类多选、数量、全隐藏／恢复、点击详情及来源；任务和路标可独立开关。

任务与探索点使用不同数据实体，关联通过明确的 ID 关系表达。每个探索点具有稳定 ID、地区、类型、原始坐标、转换坐标、来源版本和核对状态。优先沿用源稳定键；无稳定键的记录维护 ID 映射，不用可变坐标当永久 ID。

修改范围主要是数据生成脚本、`dist/app.js`、`dist/index.html`、`dist/style.css`，以及新增探索点数据。保留现有静态架构和 Sites 身份，不为图层引入账号系统。

验收：

- 与独立冻结清单做差集核对，逐条解释遗漏、合并或排除；区域归属和坐标转换有独立样例。
- 任意图层组合的点数与清单一致；探索层开关不破坏任务筛选、路标开关与选中详情。
- 既有 267 个任务 ID 和来源说明保留，现有交互、剧透保护和结局规则持续通过。
- 390×844 手机及桌面无横向溢出，关键操作可点击、可用键盘访问，无页面异常或意外资源失败。
- 测量新增点位后的密集区交互，再决定视野裁剪、聚合或 Canvas；不一次把 978 个候选全画上地图。

### 第 2 轮：个人进度、备份和分享（P0／P1，已实现）

为任务与探索点提供完成标记、收藏、隐藏已完成和计数。先使用设备本地存储，保存地区、筛选、视野及决策选择；剧透显示仍默认隐藏。记录包含存储版本、数据版本和稳定 ID。

提供个人进度 JSON 导出／导入；与当前“下载任务数据”明确区分。分享链接至少支持指定地区和任务，也可支持探索点。链接不夹带个人笔记、进度或决策后果；浏览器前进／后退与选中状态一致。

验收：

- 标记／取消后刷新和新标签页可恢复；隐藏已完成时数量与图层一致。
- 导出→清空测试存储→导入后的状态等价；格式损坏、未知版本和失效 ID 有明确处理，原有记录不会被无效导入覆盖。
- 更新数据或校准坐标不会因点位 ID 改变而丢失进度；不能迁移的记录单独列出。
- 分享链接可直达指定对象，未知 ID 有可理解的提示；前进／后退可靠，打开链接不自动展开剧透。
- 存储不可用时地图仍可使用，并明确告知保存失败。

### 第 3 轮：委托、寻宝、昆特与服务点（P1，已实现）

按“狩魔委托 → 猎魔人套装搜集 → 其他寻宝 → 昆特人物／售牌 → 随机遭遇”分批补齐。每批先做两套来源的对照表，再整理中文名称、接取方式、前置／错过条件、地区、资料片与位置语义。已收录的昆特／竞赛任务继续保留；新增的是独立分类与具体点位资料。

扩充任务类型时同时更新列表、地图图标、详情文案、筛选与 WebMCP 返回类型，避免把所有新类型继续显示成“支线”。商人、工匠、怪物巢穴和宝藏图层按用途归组，不把资源点硬塞成任务。

验收：

- 独立来源对照表没有未解释差集；明确版本与计数口径，不宣称未经证明的全游戏覆盖。
- 不重复计入任务阶段、总任务、任务目标或探索点；接取位置、任务目标和关联地标可区分。
- 每条新增内容有可检查来源；没有可靠坐标的条目仍可从目录访问。
- 主线／支线旧筛选与资料片边界不退化，新类型可检索、定位与查看详情。
- 更新当前硬编码 267／类型计数的测试，使用独立审核清单与旧 ID 保留检查；不只用新数据自己验证自己。

## 每轮验证与 Site 版本关联

每轮遵循“独立来源清单 → 数据生成与语义核对 → 有限功能实现 → 数据规则检查 → 相关桌面／手机浏览器检查 → 报告与资源检查 → 发布验证”。没有源文件变化时复用成功结果；只有新改动或未解决问题才扩展测试。

冻结来源保留在 `evidence/`，新一轮结果使用带环境和时间的独立记录。每项记录包含源码／数据摘要、执行环境、通过／失败／未执行状态；新增位置在实机核对前继续标明社区或近似来源。

发布时沿用同一 Site：

1. 将这一轮最终源码提交并推送到既有 `origin`。
2. 从同一已推送提交生成发布归档，`save_site_version` 的 `source.commit_sha` 必须对应该提交。
3. 发布返回的版本 ID，并检查部署最终状态为 `succeeded`；保持现有公开访问设置。
4. 记录 `Site vN → Git 提交 SHA → 产物摘要 → 本轮验证结果`，需要时创建追溯标签。

发布完成后，由 Sites 版本记录绑定最终推送提交；发布归档只从该提交的 `dist/` 和 `.openai/hosting.json` 生成。当前发布记录不预填尚未确认的版本号。
